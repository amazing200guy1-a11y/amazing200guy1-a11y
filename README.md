## Engineering Principles

- **Fail-closed integrity** — any oracle divergence, consensus shortfall or risk breach aborts the path before external side-effects.
- **Explicit latency contracts** — every hot path publishes a hard microsecond budget.
- **Zero-trust boundaries** — inputs are authenticated, schema-validated and rate-limited before reaching core logic.
- **Observable by construction** — counters, versioned state and structured logs are first-class.
- **Polyglot without chaos** — clear ownership of data structures and hand-off protocols across language runtimes.
